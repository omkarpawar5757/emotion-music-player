# Emotion Based Music Player 🎵

## 📌 Description
This project detects user emotions and plays songs accordingly.

## 🚀 Features
- Face detection
- Emotion recognition
- Auto music suggestion

## 🛠 Technologies Used
- HTML, CSS, JavaScript
- Java Backend
